# blurCam - Product Specification

## 概要

blurCamは、iPhone向けのプライバシー保護カメラアプリである。ユーザーが事前に自分の顔を登録すると、撮影中に登録済み人物だけを通常表示し、それ以外の人物にはリアルタイムでモザイク（ガウシアンブラー）を自動適用する。iPhone純正カメラのようなシンプルでミニマルなUIを通じて、「AIを使っている」ではなく「普通に撮っただけなのに、周囲が自然に保護されている」という体験を提供する。

## ターゲットユーザー

| ユーザー層 | 利用シーン |
|---|---|
| イベント・パーティの参加者 | 友人だけを写し、周囲の見知らぬ人のプライバシーを守りたい |
| 子どもの保護者 | 運動会・発表会で自分の子どもだけを撮影し、他の子どもの顔を保護したい |
| SNS投稿者 | 街中や人混みで撮影した写真・動画を、第三者の顔を気にせず投稿したい |
| プライバシー意識の高いユーザー | 日常的にプライバシーに配慮した撮影を習慣にしたい |

## 機能一覧

### 優先度: 高（MVP必須）

| # | 機能 | 説明 |
|---|---|---|
| F1 | オンボーディング（顔登録） | 初回起動時にユーザーの顔を正面から撮影し、端末内に顔データを登録する。登録完了後、プライバシー保護が有効になることを案内する |
| F2 | カメラプレビュー | フルスクリーンのカメラプレビューを表示する。iPhone純正カメラのようなミニマルなレイアウト（上部: フラッシュ・設定、中央: カメラ映像、下部: シャッター・モード切替・ギャラリー） |
| F3 | リアルタイム顔検出・識別 | カメラプレビュー中に顔をリアルタイムで検出し、登録済みの顔かどうかを識別する。登録済みの顔は通常表示、未登録の顔にはガウシアンブラー（ソフトモザイク）を適用する |
| F4 | 写真撮影 | シャッターボタンをタップして写真を撮影する。撮影された写真には未登録の顔にブラー処理が適用された状態で保存される |
| F5 | 動画撮影 | 写真/動画モードを切り替え、動画を録画する。録画中もリアルタイムで未登録の顔にブラー処理が適用され、その状態で動画が保存される |
| F6 | カメラ権限リクエスト | カメラ・マイク・フォトライブラリへのアクセス権限を適切にリクエストし、権限が拒否された場合は設定画面への導線を表示する |

### 優先度: 中

| # | 機能 | 説明 |
|---|---|---|
| F7 | 前面/背面カメラ切替 | フロントカメラとバックカメラをワンタップで切り替える |
| F8 | フラッシュ制御 | フラッシュのオン/オフ/自動を切り替える |
| F9 | 撮影済みメディア確認 | 直近の撮影結果をサムネイルからプレビューできる |
| F10 | 登録済み顔の管理 | 登録済みの顔を一覧表示し、追加・削除ができる設定画面 |
| F11 | ブラー強度設定 | モザイク（ブラー）の強度をユーザーが調整できる |

### 優先度: 低

| # | 機能 | 説明 |
|---|---|---|
| F12 | 複数人の顔登録 | 家族・友人など複数人の顔を登録し、全員を保護対象外にできる |
| F13 | ズーム操作 | ピンチジェスチャーでカメラのズームイン/アウトができる |

### 優先度: 高（ライブ配信機能）

| # | 機能 | 説明 |
|---|---|---|
| F14 | RTMP配信エンジン | HaishinKitを使用してRTMPプロトコルでライブ配信を行う。VideoFrameProcessorの処理済みPixelBufferを配信入力として使用し、顔ブラー適用済みの映像をリアルタイムで送出する |
| F15 | 配信先設定 | RTMP URLとストリームキーを設定画面から入力・保存できる。YouTube Live、Twitch、カスタムRTMPサーバーなど複数のプリセットを用意し、配信先を切り替え可能にする |
| F16 | 配信操作UI | カメラ画面から配信の開始・停止を行えるUI。配信中は配信状態インジケーター（ライブバッジ）、経過時間、停止ボタンを表示する |
| F17 | 配信音声キャプチャ | 配信映像にマイク音声を含める。既存のAudioSampleBufferキャプチャ機構を活用し、映像と音声を同期して配信する |

## 技術スタック推奨

| カテゴリ | 推奨技術 |
|---|---|
| プラットフォーム | iOS 17.0以上 |
| 言語 | Swift |
| UIフレームワーク | SwiftUI |
| カメラ制御 | AVFoundation |
| 顔検出 | Vision Framework (VNDetectFaceRectanglesRequest) |
| 顔識別 | Vision Framework (VNGenerateFaceObservationsRequest) + CoreML |
| 画像処理（ブラー） | Core Image (CIFilter - CIGaussianBlur) / Metal |
| 動画処理 | AVAssetWriter + リアルタイムフレーム処理 |
| ライブ配信 | HaishinKit (RTMP) |
| ローカルデータ保存 | Core Data / FileManager（顔データの端末内保存） |
| アーキテクチャ | MVVM推奨 |

## 非機能要件

| 項目 | 要件 |
|---|---|
| プライバシー | 顔データは端末内のみで処理・保存する。クラウド送信・サーバー保存は一切行わない |
| パフォーマンス | カメラプレビューのフレームレートは最低20fps以上を維持する（ブラー処理適用時） |
| 対応デバイス | iPhone 12以降（A14 Bionicチップ以上を推奨） |
| ストレージ | 撮影した写真・動画はiPhoneのフォトライブラリに保存する |
| アクセシビリティ | VoiceOver対応。主要なUI要素にアクセシビリティラベルを設定する |
| ローカライゼーション | 初期リリースは日本語のみ。将来的に英語対応可能な構造とする |
