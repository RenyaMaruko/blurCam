# Sprint 8: 配信先設定と配信プリセット

## 目的

配信先（RTMP URLとストリームキー）を設定画面から管理できるようにする。YouTube Live、Twitchなど主要なプラットフォームのプリセットを用意し、ユーザーが簡単に配信先を切り替えられる設計にする。設定した配信先情報はアプリ再起動後も保持される。

## 実装する機能

- **配信先設定画面（F15）**: 設定画面に配信先の管理セクションを追加する。RTMP URLとストリームキーを入力・保存でき、保存済みの配信先を一覧表示・選択・削除できる
- **配信プラットフォームプリセット**: YouTube Live、Twitch、カスタムRTMPの3種類のプリセットを用意する。プリセット選択時にRTMP URLが自動入力され、ユーザーはストリームキーのみ入力すればよい
- **配信先の切り替え**: 保存済みの複数の配信先から、使用する配信先をワンタップで切り替えられる

## スプリント契約（完了条件）

以下の全条件を満たした場合のみ、このスプリントは完了とする。

### 配信先設定画面

- [ ] 設定画面に「配信設定」セクションが表示されている
- [ ] 「配信設定」セクションをタップすると、配信先の管理画面に遷移する
- [ ] 配信先管理画面に「配信先を追加」ボタンが表示されている
- [ ] 「配信先を追加」ボタンをタップすると、配信先の入力フォームが表示される

### 配信プラットフォームプリセット

- [ ] 配信先の入力フォームで「YouTube Live」「Twitch」「カスタムRTMP」の3つからプラットフォームを選択できる
- [ ] 「YouTube Live」を選択すると、RTMP URLフィールドにYouTubeのインジェストURLが自動入力される
- [ ] 「Twitch」を選択すると、RTMP URLフィールドにTwitchのインジェストURLが自動入力される
- [ ] 「カスタムRTMP」を選択すると、RTMP URLフィールドが空欄で表示され、ユーザーが自由に入力できる
- [ ] いずれのプリセットでも、ストリームキーフィールドはユーザーが手動入力する

### 配信先の保存と管理

- [ ] RTMP URLとストリームキーを入力して「保存」すると、配信先が一覧に追加される
- [ ] 保存済みの配信先が一覧で表示される（プラットフォーム名、URL概要が確認できる）
- [ ] 保存済みの配信先を削除できる
- [ ] 削除時に確認ダイアログが表示される
- [ ] 保存した配信先情報はアプリを再起動しても保持されている
- [ ] ストリームキーは画面上でマスク表示（***）されており、タップまたはトグルで表示/非表示を切り替えられる

### 配信先の選択と切り替え

- [ ] 保存済みの配信先一覧から、使用する配信先をタップして選択できる
- [ ] 現在選択中の配信先が視覚的に区別できる（チェックマーク、ハイライトなど）
- [ ] カメラ画面で配信を開始すると、現在選択中の配信先に対して接続される
- [ ] 配信先が未選択の状態で配信開始ボタンをタップすると、配信先の設定を促すメッセージが表示される

### バリデーション

- [ ] RTMP URLが空の状態で保存しようとすると、エラーメッセージが表示される
- [ ] ストリームキーが空の状態で保存しようとすると、エラーメッセージが表示される
- [ ] RTMP URLの形式が明らかに不正な場合（rtmp:// で始まらないなど）、エラーメッセージが表示される

### 既存機能の維持

- [ ] 写真撮影（ブラー適用済み）が正常に動作する
- [ ] 動画撮影（ブラー適用済み）が正常に動作する
- [ ] カメラ切替・フラッシュ・メディアプレビュー・ズームが正常に動作する
- [ ] 顔管理・ブラー強度設定が正常に動作する
- [ ] Sprint 7で実装した配信の開始・停止が正常に動作する
