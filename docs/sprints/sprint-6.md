# Sprint 6: 顔管理・設定画面とエッジケース対応

## 目的

登録済みの顔を管理する設定画面を実装し、アプリの完成度を高める。複数人の顔登録、ブラー強度設定、エッジケース（権限変更・顔データ消失等）への対応を行い、プロダクトとしての品質を仕上げる。

## 実装する機能

- **登録済み顔の管理画面（F10）**: 登録済みの顔を一覧表示し、新しい顔の追加・既存の顔の削除ができる設定画面
- **複数人の顔登録（F12）**: 家族や友人など複数人の顔を登録し、全員をブラー対象外にできる
- **ブラー強度設定（F11）**: モザイク（ブラー）の強度をスライダーで調整できる
- **エッジケース対応**: 権限が後から取り消された場合、顔データが存在しない場合など、異常系の適切なハンドリング

## スプリント契約（完了条件）

以下の全条件を満たした場合のみ、このスプリントは完了とする。

### 設定画面へのアクセス

- [ ] カメラ画面上部に設定アイコン（ギアアイコン）が表示されている
- [ ] 設定アイコンをタップすると設定画面が表示される
- [ ] 設定画面からカメラ画面に戻れる

### 登録済み顔の管理

- [ ] 設定画面に登録済みの顔の一覧が表示される（顔のサムネイル画像付き）
- [ ] 各顔に対して「削除」操作ができる
- [ ] 顔を削除する際に確認ダイアログが表示される
- [ ] 顔を削除すると、その顔はカメラプレビューでブラー対象（未登録扱い）になる
- [ ] 全ての顔を削除した場合、オンボーディング（顔登録）フローに戻る

### 複数人の顔登録

- [ ] 設定画面に「顔を追加」ボタンが表示される
- [ ] 「顔を追加」ボタンをタップすると、Sprint 2と同様の顔キャプチャフローが開始される
- [ ] 新しい顔を登録すると、一覧に追加される
- [ ] 複数人が登録されている状態で、カメラプレビューにおいて登録済みの全員がブラー対象外になる

### ブラー強度設定

- [ ] 設定画面にブラー強度を調整するスライダーが表示される
- [ ] スライダーを動かすと、ブラーの強度が「弱」「中」「強」程度の段階で変化する
- [ ] 設定したブラー強度がカメラプレビューおよび撮影結果に反映される
- [ ] ブラー強度の設定はアプリを再起動しても保持される

### エッジケース対応

- [ ] カメラ権限がiOS設定から後で取り消された場合、アプリ起動時に権限要求画面が表示される
- [ ] 顔データが何らかの理由で消失した場合、オンボーディングフローに戻る
- [ ] 設定画面の操作中にアプリがクラッシュしない

### 既存機能の維持

- [ ] 写真撮影（ブラー適用済み）が正常に動作する
- [ ] 動画撮影（ブラー適用済み）が正常に動作する
- [ ] カメラ切替・フラッシュ・メディアプレビューが正常に動作する
- [ ] モード切替（写真/動画）が正常に動作する
