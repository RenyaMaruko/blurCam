## Sprint 11: YouTube配信設定UI

### 実装する機能

- **F21 YouTube配信設定UI**: 既存のYouTube Live配信先の編集画面内に「ライブの詳細設定」ボタンを追加し、タップするとYouTube API連携の詳細設定画面に遷移する。詳細設定画面にはGoogleアカウント情報の表示（プロフィール画像・名前・メール）、ログイン/ログアウトボタン、配信タイトル・説明文の入力フォーム、公開設定（公開/限定公開/非公開）の選択、詳細オプション（カテゴリ・遅延モード・チャットON/OFF・DVR ON/OFF）を配置する。

- **既存UI構成の維持**: プラットフォーム選択肢は既存の「YouTube Live」「Twitch」「カスタムRTMP」のまま変更しない。YouTube Live選択時の配信先編集画面は従来の名前・RTMP URL・ストリームキーのフォームを維持し、その下に「ライブの詳細設定」ボタンを追加する形とする。

- **配信フローの分岐**: Googleログイン済みかつ詳細設定が入力されている場合、配信開始時にAPI経由でbroadcast/streamを自動作成しストリームキー手動入力を不要にする。未ログインの場合は従来通り手動ストリームキーで配信する。

- **配信設定の永続化**: YouTube配信の設定値（タイトル・説明文・公開設定・カテゴリ・遅延・チャット・DVR）をローカルに保存し、次回配信時にデフォルト値として復元する。

### 画面構成

```
配信先の編集画面（YouTube Live選択時）
├── 名前
├── RTMP URL（プリセット）
├── ストリームキー
├── ────────────────────
├── [ライブの詳細設定 >]  ← NavigationLink
│    └── YouTube詳細設定画面
│         ├── Googleアカウント（ログイン/ログアウト）
│         ├── タイトル
│         ├── 説明文
│         ├── 公開設定（公開/限定公開/非公開）
│         ├── カテゴリ
│         ├── 遅延設定（通常/低遅延/超低遅延）
│         ├── チャット ON/OFF
│         ├── DVR ON/OFF
│         └── サムネイル
├── ────────────────────
├── [保存]
└── [この配信先を削除]（編集時のみ）
```

### スプリント契約（完了条件）
以下の全条件を満たした場合のみ、このスプリントは完了とする。

#### ライブの詳細設定ボタン
- [ ] YouTube Live選択時の配信先編集画面に「ライブの詳細設定」ボタンが表示される
- [ ] Twitch/カスタムRTMP選択時には「ライブの詳細設定」ボタンは表示されない
- [ ] ボタンをタップするとYouTube詳細設定画面に遷移する

#### Googleアカウント表示
- [ ] YouTube詳細設定画面の上部に、ログイン済みの場合はGoogleアカウントのプロフィール画像・表示名・メールアドレスが表示される
- [ ] 未ログイン時は「Googleでログイン」ボタンが表示され、タップするとGoogle Sign-Inフローが開始される
- [ ] ログイン済み時は「ログアウト」ボタンが表示され、タップするとサインアウトして未ログイン表示に切り替わる

#### 配信タイトル・説明文
- [ ] 配信タイトルの入力欄があり、テキストを入力できる
- [ ] 配信タイトルが空の場合、保存時にバリデーションエラーが表示される
- [ ] 配信説明文の入力欄があり、複数行のテキストを入力できる
- [ ] 説明文は空でも保存可能（任意フィールド）

#### 公開設定
- [ ] 「公開」「限定公開」「非公開」の3つの選択肢が選択できる
- [ ] デフォルトは「非公開」が選択されている
- [ ] 選択状態が視覚的にわかる（選択中の項目にチェックマークやハイライトがある）

#### 詳細オプション
- [ ] カテゴリ選択があり、YouTubeの配信カテゴリ（ゲーム、エンタメ、教育など）から選択できる
- [ ] 遅延設定が選択でき、「通常遅延」「低遅延」「超低遅延」の3つのオプションがある
- [ ] チャットON/OFFのトグルスイッチがあり、切り替えられる
- [ ] DVR ON/OFFのトグルスイッチがあり、切り替えられる

#### 配信フローの分岐
- [ ] Googleログイン済みかつタイトルが設定されている場合、配信開始時にAPI経由でbroadcast/streamが自動作成される
- [ ] API経由で作成された場合、ストリームキーの手動入力なしで配信が開始される
- [ ] 未ログインの場合、従来通り手動入力のストリームキーで配信される
- [ ] Twitch/カスタムRTMPの既存配信先が正常に表示・選択・編集・削除できる（回帰）

#### 設定値の永続化
- [ ] 配信タイトル・説明文・公開設定・カテゴリ・遅延・チャット・DVRの設定値が保存され、画面を閉じて再度開いても前回の設定値が復元される
- [ ] 設定値の保存は既存のRepositoryパターンに従っている
