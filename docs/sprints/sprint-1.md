# Sprint 1: カメラ基盤とプレビュー表示

## 目的

アプリの土台となるカメラプレビュー画面を構築する。iPhone純正カメラのようなミニマルなレイアウトでカメラ映像をフルスクリーン表示し、写真撮影ができる状態にする。この段階ではまだ顔検出・ブラー処理は行わない。

## 実装する機能

- **カメラ権限リクエスト（F6）**: カメラへのアクセス権限をリクエストし、未許可時に適切な案内を表示する
- **カメラプレビュー表示（F2）**: バックカメラのリアルタイム映像をフルスクリーンで表示する。上部にステータスエリア、下部にシャッターボタンとモード切替エリアを配置する
- **写真撮影（F4の基本部分）**: シャッターボタンをタップして写真を撮影し、フォトライブラリに保存する（この段階ではブラー処理なし）

## スプリント契約（完了条件）

以下の全条件を満たした場合のみ、このスプリントは完了とする。

### カメラ権限

- [ ] アプリ初回起動時にカメラへのアクセス権限のリクエストダイアログが表示される
- [ ] カメラ権限が許可されると、カメラプレビュー画面に遷移する
- [ ] カメラ権限が拒否されている場合、「カメラへのアクセスを許可してください」というメッセージと、iOS設定画面を開くボタンが表示される

### カメラプレビュー

- [ ] カメラプレビューがデバイスのフルスクリーン（セーフエリアを含む）で表示される
- [ ] カメラ映像がリアルタイムで滑らかに描画される（目視で明らかなカクつきがない）
- [ ] 画面上部にステータスバーエリアが存在する（フラッシュアイコンの表示位置が確保されている）
- [ ] 画面下部にシャッターボタンが中央に配置されている
- [ ] シャッターボタンは円形で、タップ可能な十分なサイズ（44pt以上）がある

### 写真撮影

- [ ] シャッターボタンをタップすると写真が撮影される
- [ ] 撮影した写真がiPhoneのフォトライブラリに保存される
- [ ] 撮影時にシャッターボタンに視覚的なフィードバック（アニメーションまたは色変化）がある
- [ ] フォトライブラリへの保存権限が未許可の場合、権限リクエストが表示される

### プロジェクト構造

- [ ] Xcodeプロジェクトが作成されており、ビルドが成功する
- [ ] iOS 17.0以上をターゲットとして設定されている
- [ ] SwiftUIで画面が構築されている
