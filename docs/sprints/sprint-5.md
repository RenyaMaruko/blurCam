# Sprint 5: カメラ操作の拡充と撮影体験の仕上げ

## 目的

カメラアプリとしての操作性を向上させる。前面/背面カメラの切替、フラッシュ制御、撮影結果のプレビュー機能を実装し、iPhone純正カメラに近い撮影体験を完成させる。

## 実装する機能

- **前面/背面カメラ切替（F7）**: フロントカメラとバックカメラをワンタップで切り替える。切替後も顔検出・ブラー処理が正常に動作する
- **フラッシュ制御（F8）**: フラッシュのオン/オフ/自動をトグルで切り替える
- **撮影済みメディア確認（F9）**: 直近の撮影結果をサムネイルからタップしてプレビューできる

## スプリント契約（完了条件）

以下の全条件を満たした場合のみ、このスプリントは完了とする。

### カメラ切替

- [ ] カメラ画面にカメラ切替ボタン（フリップアイコン）が表示されている
- [ ] ボタンをタップすると、フロントカメラとバックカメラが切り替わる
- [ ] カメラ切替後もリアルタイム顔検出とブラー処理が正常に動作する
- [ ] カメラ切替時にアニメーション（フリップなど）が付いている
- [ ] フロントカメラでも登録済みの顔が正しく識別される

### フラッシュ制御

- [ ] カメラ画面上部にフラッシュアイコンが表示されている
- [ ] フラッシュアイコンをタップするたびに、オフ → 自動 → オン の順に切り替わる
- [ ] 現在のフラッシュ状態がアイコンまたはテキストで視覚的にわかる
- [ ] フラッシュ「オン」の状態で写真を撮影すると、フラッシュが発光する
- [ ] 動画撮影中はフラッシュがトーチ（常時点灯）として動作する

### 撮影済みメディア確認

- [ ] カメラ画面の左下に、直近に撮影した写真または動画のサムネイルが表示される
- [ ] サムネイルをタップすると、撮影したメディアのプレビュー画面が表示される
- [ ] プレビュー画面で写真はフルスクリーンで表示される
- [ ] プレビュー画面で動画は再生ボタンをタップして再生できる
- [ ] プレビュー画面からカメラ画面に戻れる

### 既存機能の維持

- [ ] 写真撮影（ブラー適用済み）が正常に動作する
- [ ] 動画撮影（ブラー適用済み）が正常に動作する
- [ ] モード切替（写真/動画）が正常に動作する
