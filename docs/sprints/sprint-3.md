# Sprint 3: リアルタイム顔検出とブラー処理

## 目的

アプリのコア機能であるリアルタイム顔検出・識別とブラー処理を実装する。カメラプレビュー中に登録済みの顔と未登録の顔を区別し、未登録の顔にガウシアンブラーを自動適用する。この処理を写真撮影にも反映させる。

## 実装する機能

- **リアルタイム顔検出・識別（F3）**: カメラフレームごとに顔を検出し、Sprint 2で登録した顔データと照合して登録済み/未登録を判定する
- **リアルタイムブラー処理（F3）**: 未登録の顔にガウシアンブラーをリアルタイムで適用し、カメラプレビューに反映する。登録済みの顔は通常表示する
- **ブラー適用済み写真撮影（F4の完成）**: 撮影した写真に未登録の顔のブラー処理が適用された状態で保存する

## スプリント契約（完了条件）

以下の全条件を満たした場合のみ、このスプリントは完了とする。

### リアルタイム顔検出

- [ ] カメラプレビュー中に画面内の人物の顔がリアルタイムで検出される
- [ ] 複数の顔が同時に画面内に存在する場合、それぞれ個別に検出される
- [ ] 顔が画面に入ってから検出されるまで、目視で明らかな遅延がない（概ね0.5秒以内）

### 顔識別とブラー処理

- [ ] 登録済みの顔（Sprint 2で登録した顔）は通常表示（ブラーなし）される
- [ ] 未登録の顔にはガウシアンブラー（ソフトモザイク）がリアルタイムで適用される
- [ ] ブラーは顔の領域に限定して適用され、背景や身体部分にはブラーがかからない
- [ ] 人物が動いてもブラーが顔の位置に追従する
- [ ] ブラー処理中もカメラプレビューが滑らかに表示される（明らかなフレーム落ちがない）

### 登録済み顔の表示

- [ ] 登録済みの顔の周囲に、控えめな視覚的インジケーター（薄い枠など）が表示される（過剰な演出でないこと）
- [ ] 登録済みの顔が動いてもインジケーターが追従する

### ブラー適用済み写真撮影

- [ ] シャッターボタンをタップして撮影した写真に、未登録の顔のブラーが適用された状態で保存される
- [ ] 撮影した写真を確認すると、登録済みの顔はクリアに写り、未登録の顔にはブラーがかかっている
- [ ] 撮影した写真のブラー処理は後から解除できない（保存された時点でブラーが焼き込まれている）

### パフォーマンス

- [ ] ブラー処理適用中のカメラプレビューが、目視でカクつきを感じない程度のフレームレートを維持する
- [ ] 画面内に3人以上の顔が存在する状態でも、顔検出とブラー処理が動作する
