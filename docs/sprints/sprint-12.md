## Sprint 12: YouTube配信ライフサイクル管理とサムネイル

### 実装する機能

- **F22 YouTube配信ライフサイクル管理**: 配信開始時にbroadcastステータスをtesting→liveに自動遷移させ、配信停止時にcompleteに遷移させる一連のライフサイクルを管理する。ストリームのhealth状態（good/ok/bad/noData）をポーリングで監視し、status表示をUIに反映する。配信中にタイトル・説明文を更新できるliveBroadcasts.update呼び出しも実装する。

- **F23 サムネイルアップロード**: フォトライブラリから画像を選択し、YouTube Thumbnails APIでサムネイルをアップロードする。配信作成後・配信中いずれのタイミングでも設定・変更可能にする。

### スプリント契約（完了条件）
以下の全条件を満たした場合のみ、このスプリントは完了とする。

#### broadcastライフサイクル
- [ ] YouTube配信開始ボタンを押すと、broadcast作成→stream作成→bind→RTMP接続→ストリームhealth監視→testing遷移→live遷移の一連のフローが自動実行される
- [ ] broadcastのステータス遷移（created→testing→live）がAPI経由で正しく行われる
- [ ] 配信停止ボタンを押すと、RTMP切断後にbroadcastステータスがcompleteに遷移する
- [ ] broadcastステータス遷移に失敗した場合（APIエラー）、エラーメッセージがユーザーに表示される

#### ストリームhealth監視
- [ ] 配信中にliveStreams.listをポーリングし、ストリームのhealthStatus（good/ok/bad/noData）を取得している
- [ ] ストリームhealthが「good」または「ok」のときに配信状態が正常であることがUIに表示される
- [ ] ストリームhealthが「bad」のとき、警告がUIに表示される（例: 「配信品質が低下しています」）
- [ ] ストリームhealthが「noData」のまま一定時間（30秒以上）経過した場合、接続に問題がある旨の警告が表示される
- [ ] ポーリング間隔は配信中のみ有効で、配信停止時にはポーリングも停止する

#### 配信中のメタデータ更新
- [ ] 配信中にタイトルを変更して保存すると、liveBroadcasts.updateが呼ばれ、YouTubeの配信タイトルが更新される
- [ ] 配信中に説明文を変更して保存すると、YouTubeの配信説明文が更新される
- [ ] メタデータ更新に失敗した場合、エラーメッセージが表示されるが配信自体は継続する

#### サムネイル
- [ ] YouTube配信設定画面に「サムネイル」の設定エリアがあり、画像のプレビューが表示される
- [ ] 「サムネイルを選択」ボタンをタップすると、PHPickerViewController（フォトライブラリ）が表示される
- [ ] 画像を選択すると、設定画面にサムネイルのプレビューが表示される
- [ ] 配信作成時に選択済みのサムネイルがYouTube Thumbnails APIでアップロードされる
- [ ] サムネイルを未選択のまま配信を開始しても、エラーにならず配信が開始される（サムネイルは任意）
- [ ] サムネイルアップロードに失敗した場合、エラーメッセージが表示されるが配信作成自体は継続する
