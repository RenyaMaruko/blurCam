# Sprint 9: 配信中UIの完成とエッジケース対応

## 目的

配信中のユーザー体験を仕上げる。配信経過時間の表示、配信品質のフィードバック、配信中の操作制限、バックグラウンド遷移時の挙動など、プロダクト品質のライブ配信機能を完成させる。

## 実装する機能

- **配信中UIの完成（F16の完成）**: 配信経過時間のリアルタイム表示、配信停止時の確認ダイアログ、配信中の視覚的状態をカメラ画面全体に反映する
- **配信中の操作制限と安全策**: 配信中に録画を開始できないようにする（初期リリースでは排他制御）。配信中のカメラ切替時に配信が途切れない、または適切に再接続する
- **バックグラウンド・エッジケース対応**: アプリがバックグラウンドに移行した際の配信停止処理、配信中の着信、長時間配信時の安定性を担保する

## スプリント契約（完了条件）

以下の全条件を満たした場合のみ、このスプリントは完了とする。

### 配信経過時間

- [ ] 配信中は画面上部に配信経過時間が「HH:MM:SS」形式でリアルタイム表示される
- [ ] 経過時間は配信開始時点から正確にカウントアップされる
- [ ] 配信を停止すると経過時間の表示が消える

### 配信状態の視覚的フィードバック

- [ ] 配信中は「LIVE」バッジが赤色で画面上部に常時表示される
- [ ] 「LIVE」バッジは点滅アニメーション等で配信中であることを強調する
- [ ] 配信中はシャッターボタン周辺のUIが配信モードであることを示す状態に変化する（色変化やアイコン変化など）

### 配信停止の安全確認

- [ ] 配信中に停止ボタンをタップすると、「配信を終了しますか？」の確認ダイアログが表示される
- [ ] 確認ダイアログで「終了」を選択すると配信が停止される
- [ ] 確認ダイアログで「キャンセル」を選択すると配信が継続される

### 配信と録画の排他制御

- [ ] 配信中は動画撮影（録画）の開始ができない状態になっている（ボタン無効化またはモード切替不可）
- [ ] 録画中は配信の開始ができない状態になっている（ボタン無効化）
- [ ] 排他制御の理由がユーザーに伝わる（「配信中は録画できません」等のメッセージまたはツールチップ）

### カメラ切替時の配信維持

- [ ] 配信中にフロント/バックカメラを切り替えても、配信が中断せず継続される
- [ ] カメラ切替後も、切替先のカメラで撮影されたブラー処理済み映像が配信される

### バックグラウンド遷移

- [ ] 配信中にアプリがバックグラウンドに移行した場合、配信が自動的に停止される
- [ ] アプリがフォアグラウンドに復帰した際、配信が停止済みであることがUIに反映されている（「LIVE」バッジが消え、経過時間が非表示）
- [ ] バックグラウンド移行による配信停止後、再度配信を開始できる

### エッジケース

- [ ] 配信中にネットワーク接続が不安定になった場合、接続状態の変化がUIに反映される（警告表示など）
- [ ] 写真撮影は配信中でも正常に動作する（配信には影響しない）
- [ ] 配信開始から配信停止までの一連の操作でメモリリークが発生しない（配信の開始・停止を5回繰り返してもアプリがクラッシュしない）

### 既存機能の維持

- [ ] 配信を行っていない状態で、写真撮影（ブラー適用済み）が正常に動作する
- [ ] 配信を行っていない状態で、動画撮影（ブラー適用済み）が正常に動作する
- [ ] カメラ切替・フラッシュ・メディアプレビュー・ズームが正常に動作する
- [ ] 設定画面の顔管理・ブラー強度設定・配信先設定が正常に動作する
