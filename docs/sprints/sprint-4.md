# Sprint 4: 動画撮影とモード切替

## 目的

写真に加えて動画撮影に対応する。iPhone純正カメラのようなモード切替UIを実装し、写真モードと動画モードをスワイプまたはタップで切り替えられるようにする。動画撮影中もリアルタイムブラー処理を維持する。

## 実装する機能

- **モード切替UI**: 画面下部に写真/動画のモード切替を配置し、スワイプまたはタップで切り替えられるようにする
- **動画撮影（F5）**: 動画モードで録画を開始・停止し、リアルタイムブラー処理が適用された動画をフォトライブラリに保存する
- **録画中UI**: 録画中であることが視覚的にわかるUI（録画時間表示、シャッターボタンの変化）を表示する

## スプリント契約（完了条件）

以下の全条件を満たした場合のみ、このスプリントは完了とする。

### モード切替

- [ ] 画面下部に「写真」「動画」のモード表示がある
- [ ] モード表示をタップまたは左右スワイプで、写真モードと動画モードを切り替えられる
- [ ] 現在選択中のモードが視覚的に区別できる（ハイライト、下線、色変化など）
- [ ] モード切替時にカメラプレビューが途切れない

### 動画撮影

- [ ] 動画モードでシャッターボタンをタップすると録画が開始される
- [ ] 録画中にシャッターボタンを再度タップすると録画が停止される
- [ ] 録画された動画がフォトライブラリに保存される
- [ ] 録画された動画の中で、未登録の顔にブラーが適用されている
- [ ] 録画された動画の中で、登録済みの顔はクリアに表示されている
- [ ] 動画のブラー処理は後から解除できない（保存された時点でブラーが焼き込まれている）

### 録画中UI

- [ ] 録画中はシャッターボタンの見た目が変化する（赤い四角、脈動アニメーションなど、録画中であることが明確にわかる）
- [ ] 録画中は画面上部に録画時間（経過時間）が表示される
- [ ] 録画中は画面上部に赤い録画インジケーター（ドットなど）が表示される

### 音声

- [ ] マイク権限がリクエストされ、許可すると動画に音声が含まれる
- [ ] マイク権限が拒否されている場合でも、音声なしの動画として録画・保存ができる

### 既存機能の維持

- [ ] 写真モードでの撮影機能がSprint 3と同様に正常に動作する（ブラー適用済み写真の撮影・保存）
- [ ] モード切替後も顔検出とブラー処理が正常に動作する
